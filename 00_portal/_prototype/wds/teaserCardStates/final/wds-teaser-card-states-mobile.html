What to check

This is a live, interactive comparison — trigger each state directly on the card instead of judging from static Figma frames. Active is the one behavior actually under review for whether the base teaserCard ships animated in v1; Hover doesn't apply on touch, so it's covered on the desktop version instead.

  • Focus — Tab lands on the card first (its own visible ring), then Tab again moves to the nested link, which has its own distinct focus treatment. Two separate, sequential tab stops.
  • Active — an 18% opacity black overlay washes across the full image on tap. It's momentary and reverts to Default as soon as the tap releases — no layout or text change.
